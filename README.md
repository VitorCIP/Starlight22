# StarLight — Itens Lendários
Plugin único para Paper 26.3+.

Comando: `/starlight`

Inclui a base dos 13 itens definidos:
1 Relógio
2 Lampião
3 Bússola
4 Capacete dos Gêmeos (A/B)
5 Escudo
6 Bota
7 Batata do Bobó
8 Cabeça do Dragão
9 Poção
10 Tridente
11 Picareta
12 Espada do Caçador
13 Pena

Importante: `api-version: 26.3` significa que servidores abaixo de 26.3 recusam o plugin. Servidores posteriores podem carregar, mas Paper não garante que uma API futura mantenha toda a compatibilidade; por isso a manutenção por versão é necessária.

Esta entrega é um projeto-fonte. O JAR precisa ser compilado com Gradle/paperweight e Java 25.
